# WindWise — Flask Backend

XGBoost prediction API trained on 50,530 real wind turbine SCADA records.  
R² = 0.972 · RMSE ≈ 218 kW

---

## Folder structure expected

```
windwise-app/
├── backend/
│   ├── app.py
│   ├── train_model.py
│   ├── requirements.txt
│   ├── model.pkl          ← generated by train_model.py
│   └── Wind_Scada_datset.csv  ← copy your dataset here
└── windwise/              ← React frontend (unchanged)
```

---

## One-time setup

```bash
cd backend/

# 1. Install dependencies
pip install -r requirements.txt

# 2. Copy the dataset here
cp /path/to/Wind_Scada_datset.csv .

# 3. Train and save the model  (~30 seconds)
python train_model.py --data Wind_Scada_datset.csv

# 4. Start the API server
python app.py
# → running on http://localhost:5000
```

## API Reference

### `GET /health`
Returns `{ "status": "ok", "features": [...] }` — use to confirm the server is up.

### `POST /predict`
**Request body (JSON):**
```json
{
  "wind_speed":        8.5,
  "wind_direction":    60,
  "theoretical_power": 2100.0,
  "month":             4,
  "hour":              14,
  "week":              16
}
```

**Response:**
```json
{
  "predicted_power_kw": 1842.50,
  "capacity_pct":       51.2,
  "season":             "Spring"
}
```

| Field | Description |
|---|---|
| `wind_speed` | m/s at hub height |
| `wind_direction` | degrees 0–360 |
| `theoretical_power` | kWh from manufacturer curve (auto-estimated by frontend) |
| `month` | 1–12 |
| `hour` | 0–23 |
| `week` | 1–52 |
